1. What this program is

XLSX Application Grader scores rows in an Excel workbook. You open an .xlsx file, review one applicant (row) at a time, enter numeric grades, and store those grades in a proxy copy.

You can run it as a local Windows program or as a website. There is no login. On the website, grades stay in this browser only.

Item Meaning
.xlsx workbook The spreadsheet you open. Row 1 must be column headers. Row 2 and below are data.
Grade for: … columns Columns the app creates and fills when you submit grades. Example: Grade for: Essay.
Sum of All Grades A total column the app maintains for each row.
Config Saved layout for a workbook: which columns to grade, which to hide, and related settings.

2. How to start

Use the Windows program or the hosted website.

How you start What it does
xlsx_application_grader.exe Opens a desktop window for the grader.
xlsx_application_grader_web.exe Starts a local server and opens the grader in your default browser.
Hosted website Open the site URL in a browser. No EXE. Grades and configs stay in this browser’s storage.
  1. Open the EXE you were given, or open the website URL.
  2. Wait for the grader window or browser tab to appear.
  3. You should see Open .xlsx in the top bar.

If you close every browser tab while using the local web EXE, the local server stops after a short delay. Restart the EXE if you see Server connection lost. The hosted website does not use that server and does not show that banner.

3. Screen overview

The main screen has four work areas plus a footer.

Area Use it for
Top bar Open .xlsx, Close, File, Sheet, and config controls (Active Config, Rename, New Config, Import Config, Export Config)
Columns (left) Hide columns you do not need. Check Grade on columns you will score.
Grading (center) Enter scores, then Submit all. Optional: Copy grades.
Current row (right) Read the applicant fields. Use Prev, Next, or the Row number to move.
Footer Settings, layout toggles, theme switch, and a status line (for example No file loaded).

4. First-time grading

Do this the first time you grade a workbook.

  1. Select Open .xlsx and choose one or more .xlsx files.
  2. In Columns, check Grade beside each column you want to score.
  3. In Current row, read the applicant data. Row numbers start at 2 because row 1 is the header row.
  4. In Grading, type a number in each grade field you want to fill.
  5. Select Submit all. The app writes values into Grade for: … columns, updates Sum of All Grades, and saves.
  6. Optional: turn on Auto-advance row in Settings so Submit moves you to the next row.

Tip: Empty grade fields are skipped on submit. If every field is empty, the status shows No grades entered. Non-numeric values show Grade must be a number.

5. Working with rows and columns

5.1 Hide and show columns

  • In Columns, use the hide control on a column to remove it from view.
  • Turn on Show hidden columns in Settings when you need them back, then unhide.

5.2 Grade checkboxes

Only columns with Grade checked appear as score inputs in Grading.

5.3 Move between rows

  • Prev / Next move one row at a time.
  • Type a number in Row to jump to that Excel row.

5.4 Clear a saved grade

On a grade card in Current row, use the clear control (title Clear grade) to remove that cell’s grade and refresh the sum.

5.5 Sheets and multiple files

  • Use Sheet to switch worksheets in the open workbook.
  • Use File to switch among workbooks still open in this session.
  • Use Close to close the active file.

6. Where grades are saved

When you open a file through Open .xlsx, grades are written to a proxy copy, not to the original file you picked. The original workbook on disk is never overwritten.

Windows EXE

The proxy lives here:

%APPDATA%\xlsx_application_grader\Grades for - {workbook name}.xlsx

Example: opening Applicants.xlsx grades Grades for - Applicants.xlsx under that AppData folder.

  • If that proxy already exists, the app reuses it instead of copying again.
  • Open the graded file from AppData, or use Copy grades, when you need the results elsewhere.

Hosted website

The proxy is stored in this browser (IndexedDB), still named Grades for - {workbook name}.xlsx. It is not uploaded to the server.

  • If a proxy for that file name already exists in this browser, the site reuses it.
  • Use Copy grades to paste results into Excel.
  • Clearing site data, switching browsers, or using another device removes the proxy and configs. There is no cross-device sync.

Important: Do not assume the original workbook on your Desktop or shared drive was updated. Grades live in the proxy (AppData or this browser).

7. Copy grades

  1. Open a workbook that already has grade columns.
  2. Select Copy grades in the Grading header.
  3. Paste into Excel (or another sheet). The clipboard uses tab-separated values.

Only rows that have grade data are included, along with the grade headers and Sum of All Grades when present.

On the hosted website this is the way to get grades into Excel. The site does not write the graded workbook back to disk.

8. Configs

A config remembers how you set up grading for a workbook so you do not rebuild the layout each time.

Configs store things like:

  • Which columns are graded or hidden (per sheet)
  • Current row
  • Auto-advance row
  • Panel widths and whether the column list or header is visible

8.1 Use and rename

  • Active Config: switch among named setups for this workbook.
  • Rename: type a new name in the rename field. Duplicate names are blocked.
  • New Config: create another named setup.

8.2 Import and export

  1. Export Config saves the active config as a .json file.
  2. Import Config loads a .json config into the current workbook’s config set.

8.3 Cleanup

  1. Open Settings.
  2. Select Config Cleanup.
  3. In Stored configs, delete named configs or whole stored config files you no longer need.

On the Windows EXEs, config files are kept under %APPDATA%\xlsx_application_grader\ in native_configs or web_configs, depending on which EXE you use. On the hosted website, configs stay in this browser with the proxy files.

9. Settings and layout

Open the gear button in the footer for Settings.

Control Effect
Auto-advance row After a successful Submit all, move to the next row.
Show hidden columns List hidden columns in Columns so you can unhide them.
Config Cleanup Delete stored configs (see section 8).
Column selector toggle Hide or show the left Columns panel.
Header toggle Hide or show the top bar.
Theme switch Switch between light and dark theme. The choice is remembered.

Drag the vertical resizers between panels to change the width of Columns and Grading.

10. Quick reference

Key ideas

  • Header row: Excel row 1. Applicant data starts at row 2.
  • Grade columns: named Grade for: {header}, written on Submit.
  • Proxy file: graded copy. Windows EXE: AppData. Hosted website: this browser. The original path is not the save target.
  • Config: reusable grading layout for a workbook.

Common mistakes

  • Expected the original .xlsx to change; grades are in the proxy.
  • Entered text instead of numbers; Submit requires numeric grades.
  • Clicked Submit all with every field empty.
  • Closed all local web EXE tabs and kept grading; restart the app after a disconnect banner.
  • Re-opened the original while an old proxy already existed, then wondered why data looked “stale.”
  • Cleared browser site data on the hosted website and lost the IndexedDB proxy.

Suggested daily workflow

  1. Start the EXE or open the website, then open the application workbook.
  2. Confirm the right Active Config (or import one).
  3. Mark Grade columns if needed.
  4. Score each row with Submit all (and Auto-advance if you want).
  5. Use Copy grades when results are needed in Excel.
